# Changelog

## 1.0.3 (2026-10-30)

- Export dialog shows the actual output file name, and exports the photo on screen when no other photo
  is selected.
- Saved edits from older versions or damaged session files no longer prevent a folder from opening.
- Auto applies a smaller tint correction.
- Exported file names and thumbnail loading are logged.

## 1.0.2

- Trash icon on every filmstrip thumbnail; deleting keeps the remaining thumbnails and previews.
- The filmstrip is shown and hidden with a tab on its top edge.
- Photos open progressively: quick preview, then half resolution, then full quality.
- Auto is a toggle that restores the previous values when switched off.
- Fixed a crash when closing the app while background work was running.

## 1.0.1

- Export renders in bands on background threads: lower memory use, faster, and cancel responds
  immediately.
- Camera video-thumbnail folders are skipped.
- Warning when lens corrections are forced on for camera JPEGs.
- Faster JPEG loading.

## 1.0.0

- First release.
